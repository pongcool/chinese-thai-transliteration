  - 閎: TC hong5 ตาม Mogher (มีจุดสำเนียงซัวเถา) ส่วน HK ไม่พบใน Wiktionary, sutian และ iTaigi จึงใช้เสียงอนุมาน hong5 จาก 宏 (戶萌切 เหมือนกัน)
- ผลตัวตรวจ `python tools/check_readings_wikt.py <โฟลเดอร์> --fetch` สำหรับ 25 อักษรนี้ ไม่มีข้อทักแล้ว เหลือแค่ “Wiktionary ไม่มีข้อมูล” ของ 召 (TC) และ 閎 (HK/TC)

สิ่งที่ต้องตรวจ

1. คำอ่าน 25 อักษรใหม่ (ดูคอลัมน์ “แหล่ง” ใน TSV) ตรงกับแหล่ง เป็นเสียงอ่านแบบหนังสือ และใช้สำเนียงซัวเถา (TC) หรือไม่ จุดที่ Claude ไม่มั่นใจ:
   - 千 TC coin1 (แหล่งมี coin1/cain1 แต่ไม่ได้ระบุว่าตัวไหนเป็นเสียงหนังสือ)
   - 無 TC bhu5 / HK bu5 เทียบกับ bho5 / bô ที่ใช้ทั่วไป
   - 年 HK lian5 / TC ni5, 膠 HK kau1 / TC ga1, 鼎 HK ting2 / TC dian2, 旦 HK tan3 (แหล่งไม่มีเสียงหนังสือของ TC ให้เลือก หรือไม่ได้แยกไว้)
   - 鬲 ใช้ gé (HK kik4, TC geh4) ไม่ใช้ lì
   - 奭 TC seg4 (แปลง sêg4 ของ Wiktionary เป็นอักขรวิธีของโครงการ)
2. ผลตัวตรวจรอบ 3 ข้อ 3 บอกว่า “ตรงแหล่งแต่ยังไม่ยืนยันจุดสำเนียง” ใน 25 อักษรนี้มีตัวใดที่ Mogher หรือแหล่งอื่นให้เสียงซัวเถาต่างจากค่าใน TSV บ้าง
3. ชื่อที่อาจมีคำอ่านทั้งคำ (ข้อ 1 ของ “แหล่งคำอ่าน”) และน่าจะใช้แทนการประกอบทีละตัว: 元始天尊, 文殊, 普賢, 琵琶, 狐狸, 千年, 比干, 周公, 召公, 惡來 ถ้าพบ ให้เสนอค่าสำหรับ MD_WORD / HK_WORD / TC_WORD ใน translit_names.py พร้อมแหล่ง
4. เหตุผลเรื่อง 召 TC siao6 (เทียบจาก 邵) และ 閎 HK hong5 (อนุมานจาก 宏): ยอมรับหรือโต้แย้ง ถ้าพบแหล่งตรงให้แนบ URL (เช่น 台日大辭典 ใน minhakka2.ling.sinica.edu.tw, 潮汕字典 หรือ 潮州音字典)
