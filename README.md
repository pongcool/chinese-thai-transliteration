# Chinese–Thai Transliteration

กติกา ข้อมูลคำอ่าน และเครื่องมือถอดเสียงชื่อจีนเป็นภาษาไทย สำหรับงานแปลวรรณกรรมจีน ครอบคลุมจีนกลาง ฮกเกี้ยน และแต้จิ๋ว

ปัจจุบันมีข้อมูลตัวละครจากเฟิงเสิน (封神演義 / Fengshen Yanyi) และมีแผนเพิ่มไซอิ๋ว (西遊記 / XiYouJi) ในอนาคต

## ไฟล์หลัก

- `TRANSLITERATION.md` — กติกาถอดเสียงจีนกลาง
- `TRANSLITERATION_HOKKIEN.md` — กติกาถอดเสียงฮกเกี้ยน
- `TRANSLITERATION_TEOCHEW.md` — กติกาถอดเสียงแต้จิ๋ว
- `fengshen-characters.md` — รายชื่อตัวละครและผลถอดเสียงสามภาษา
- `tools/name_readings.tsv` — คำอ่านรายอักษรและแหล่งอ้างอิง
- `tools/translit_names.py` — สร้างคอลัมน์ถอดเสียงในตารางตัวละคร
- `tools/check_readings_wikt.py` — เทียบคำอ่านกับ Wiktionary
- `DECISIONS.md` — ข้อยุติ ข้อยกเว้น และประเด็นที่ต้องพิจารณา
- `tools/codex_review_names*.md` — บันทึกการตรวจทานแต่ละรอบ

## การใช้งาน

ใช้ Python 3 โดยสคริปต์ใช้เฉพาะ standard library ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม รันจากโฟลเดอร์โปรเจค:

```sh
python tools/translit_names.py
```

คำสั่งนี้ตรวจตัวอย่างภายในสคริปต์ก่อนสร้างสามคอลัมน์ใหม่ และเขียนทับ `fengshen-characters.md` เมื่อการตรวจผ่าน ให้แก้คำอ่านที่ `tools/name_readings.tsv` และตรวจข้อยกเว้นในสคริปต์ แทนการแก้สามคอลัมน์ผลลัพธ์โดยตรง

หากต้องการดาวน์โหลดข้อมูลและเทียบกับ Wiktionary (ต้องเชื่อมต่ออินเทอร์เน็ต):

```sh
python tools/check_readings_wikt.py .cache/wiktionary --fetch
```

ผลตรวจใช้ช่วยค้นจุดที่ต้องทบทวน คำอ่านเฉพาะชื่อ แซ่ และสำเนียงยังต้องตรวจประกอบกับแหล่งอ้างอิงและข้อยุติของโครงการ

## การใช้กับเรื่องอื่น

กติกาถอดเสียงสามารถใช้ร่วมกันได้ แต่ปัจจุบันสคริปต์ยังระบุไฟล์ `fengshen-characters.md` และข้อยกเว้นของเฟิงเสินไว้โดยตรง ก่อนเพิ่ม XiYouJi หรือเรื่องอื่น ต้องปรับให้เลือกไฟล์และข้อยกเว้นตามเรื่อง พร้อมเพิ่มคำอ่านที่ยังไม่มีและตรวจอักษรหลายเสียงตามบริบท

กติกาเป็นข้อตกลงของโครงการ ไม่ใช่มาตรฐานที่อ้างการรับรองจากหน่วยงานใด รายละเอียดแหล่งคำอ่านและข้อจำกัดอยู่ในไฟล์กติกา ข้อมูล TSV และ `DECISIONS.md`
